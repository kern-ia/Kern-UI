# Bundled fonts

Both families are licensed under the SIL Open Font License 1.1, which permits bundling
and redistribution with this application.

| Family | Files | Upstream |
|---|---|---|
| Cinzel | `cinzel-latin.woff2`, `cinzel-latin-ext.woff2` | https://fonts.google.com/specimen/Cinzel |
| Space Grotesk | `space-grotesk-latin.woff2`, `space-grotesk-latin-ext.woff2` | https://fonts.google.com/specimen/Space+Grotesk |

Space Grotesk is a variable font: one file covers every weight the interface uses, which
is why the file names carry no weight suffix.

The Vietnamese subset was dropped — the interface is French. Re-generate from the Google
Fonts CSS API if a locale ever needs it.
